# ERP 
**ERP** = Enterprise Resource Planning

En français : Progiciel de gestion intégré (PGI).

👉 C’est un logiciel tout-en-un qui gère l’ensemble des processus internes d’une entreprise, notamment :
- Comptabilité
- Gestion des stocks
- Achats / ventes
- Production
- Logistique
- RH / paie
- Approvisionnement
- Projets

🎯 Objectif : centraliser toutes les données de l’entreprise dans un système unique → éviter les doublons, fluidifier les processus, automatiser les tâches.

Les ERP les plus utilisés dans les entreprises :
- **SAP S/4HANA / SAP ERP**<br>
Le plus utilisé dans les grandes entreprises et multinationales.
- **Oracle ERP Cloud**<br>
Très utilisé dans les grandes organisations (finance, industrie, retail).
- **Microsoft Dynamics 365 Finance & Operations**<br>
Populaire dans les entreprises déjà équipées Microsoft.
- **Odoo**<br>
Open source, flexible, très populaire dans les PME / ETI.
- **Sage (Sage X3, Sage 100)**<br>
Très présent dans les PME.
- **Netsuite (Oracle)**<br>
ERP SaaS moderne très utilisé par les entreprises tech.
- **Infor ERP (LN, M3)**<br>
Utilisé dans l’industrie et la logistique.



# CRM 
**CRM** = Customer Relationship Management

En français : Gestion de la relation client.

👉 C’est un logiciel spécialisé dans la gestion commerciale et marketing :
- Gestion des contacts
- Suivi des prospects (leads)
- Pipeline commercial
- Prévisions de ventes
- Support client / ticketing
- Campagnes marketing
- Automatisation marketing (emails, scoring)

🎯 Objectif : améliorer les ventes, fidéliser les clients et suivre les interactions commerciales

Les CRM les plus utilisés dans les entreprises :
- **Salesforce**<br>
Leader mondial → très puissant, très complet, très utilisé dans les grandes entreprises.
- **Microsoft Dynamics 365 Sales**<br>
Très intégré à Office 365 et Azure → populaire chez les entreprises Microsoft.
- **HubSpot CRM**<br>
Ultra populaire pour sa version gratuite → PME, startups.
- **Zoho CRM**<br>
Solution SaaS économique, très utilisée chez les PME.
- **Pipedrive**<br>
Très apprécié des équipes commerciales (simplicité, pipeline visuel).
- **SugarCRM**<br>
CRM open source + version commerciale.
- **FreshSales (Freshworks)**<br>
Popularité croissante dans les services clients / petites entreprises.
