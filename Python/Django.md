# Django 
Django est un "framework" (ou cadre de travail) open-source écrit en Python, <br>
conçu pour créer des sites web complexes de manière rapide et structurée.

```
Imagine que tu veuilles construire une maison. 
Tu pourrais fabriquer chaque brique et chaque tuyau toi-même, 
ou bien utiliser une structure déjà prête où les fondations, 
la plomberie et l'électricité sont déjà prévues. 
Django, c'est cette structure pour le web.
```

Voici ce qu'il faut retenir de Django :

## 1. La philosophie "Batteries Included"
Django est livré avec presque tout ce dont un développeur a besoin par défaut. <br>
Contrairement à d'autres outils où tu dois choisir et installer des extensions pour chaque petite tâche, <br>
Django inclut déjà :
- Un système d'authentification (gestion des utilisateurs, connexions).
- Une interface d'administration prête à l'emploi pour gérer tes données.
- Une protection contre les failles de sécurité courantes (injections SQL, etc.).
- Une gestion de la base de données simplifiée (plus besoin d'écrire du SQL complexe).

## 2. L'architecture MVT (Modèle-Vue-Template)
Django organise le code d'une manière spécifique pour que tout soit bien rangé. <br>
C'est ce qu'on appelle l'architecture MVT :
- Modèle (Model) : C'est la structure de tes données (ta base de données).
- Vue (View) : C'est la "logique métier". C'est ici que le code décide quoi afficher en fonction de ce que l'utilisateur demande.
- Template : C'est la partie visuelle (HTML) que l'utilisateur voit sur son écran.

## Pourquoi l'utiliser ?
- Rapidité : On passe de l'idée au produit final très vite.
- Scalabilité : Il est capable de gérer d'énormes volumes de trafic. C'est d'ailleurs pour ça qu'il est utilisé par des géants comme Instagram, Pinterest ou encore Disqus.
- Sécurité : Il aide les développeurs à éviter les erreurs de sécurité classiques dès le départ.

# En résumé : 
Si Python est le langage de programmation (la langue), <br>
Django est l'outil professionnel qui utilise cette langue pour bâtir des sites web robustes <br>
sans réinventer la roue à chaque fois.
