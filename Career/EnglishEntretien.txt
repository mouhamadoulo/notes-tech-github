1️⃣ Vocabulaire clé à utiliser (indispensable)
🔹 Général / Contexte
- Business tools / Internal business applications
- Legacy applications
- Originally developed by business teams
- Lack of security compliance
- Non-compliant with security standards
- Maintenance (corrective and evolutive)
- Change requests (au lieu de EB → Evolutionary Requests / Change Requests)
- Stakeholders (business, operations, cloud team, DBA…)

🔹 Front / Back
- Frontend UI / Web interfaces
- Backend processing
- Batch processing
- Business logic
- Data processing pipelines

🔹 Infrastructure & Sécurité
- On-premise servers
- Dedicated servers
- Low Storage / insufficient RAM
- Outdated operating systems
- Secure zone / secured network
- Security compliance
- File transfer flows
- Secure file transfer (SFTP / STF)

🔹 Tests
- Connectivity testing
- Functional testing
- Non-regression testing
- User Acceptance Testing (UAT)
- Test environments

🔹 Agile / Organisation
- Agile methodology
- Daily stand-ups
- Estimation and planning
- Challenging estimates
- Cross-team collaboration

🔹 Cloud & DevOps
- Cloud migration
- Cloud-native architecture
- AWS services (EC2, RDS, S3, Lambda)
- CI/CD pipelines
- DevOps toolchain
- Automation
- Deployment pipelines

🔹 Data / Batch
- Data warehouse
- Batch jobs
- Data ingestion
- File-to-database / database-to-database
- Data aggregation
- Stored procedures
- Message queue (RabbitMQ)
- Rejected messages recycling

2️⃣ Phrases types pour l’oral (très utiles) : 
- “I was responsible for…”
- “I worked closely with business stakeholders.”
- “One of the main challenges was security compliance.”
- “We migrated legacy applications to a cloud-based architecture.”
- “I contributed to both frontend and backend development.”
- “This project significantly improved performance, security and maintainability.”
