# 1) Le créneau (stationnement parallèle)

🎯 **Objectif :** garer la voiture entre deux véhicules, parallèlement au trottoir.

### Étape 1 — Se placer

* Mets ton clignotant du côté du stationnement.
* Place-toi parallèlement à la voiture devant la place.
* Garde une distance latérale d’environ 50 cm.
* Vérifie rétroviseurs, angle mort et environnement. ([pagesjaunes][2])

```
Avant :

🚗  (voiture devant)

⬇️
🚙  ← ta voiture
```

### Étape 2 — Entrer dans la place

* Recule doucement.
* Braque fortement vers la place.
* Avance uniquement à allure lente (embrayage + frein si boîte manuelle).

```
Début :

🚗
🚙 ↘️

Puis :

🚗
  🚙 ↘️
```

### Étape 3 — Redresser

* Quand la voiture est environ à 45°, redresse les roues.
* Continue à reculer.
* Contre-braque pour aligner la voiture avec le trottoir.

### Erreurs fréquentes

❌ Aller trop vite
❌ Regarder uniquement les rétroviseurs
❌ Oublier l’avant de la voiture qui pivote

# 2) Le stationnement en bataille (parking classique)

🎯 **Objectif :** entrer dans une place perpendiculaire.

## En marche avant

1. Approche-toi doucement de la place.
2. Décale suffisamment l’avant pour avoir un bon angle.
3. Tourne progressivement.
4. Redresse quand la voiture est dans l’axe.

```
Vue du dessus :

   Place
| 🚗 |
|   |

Approche ➡️ ↘️
          🚙
```

## En marche arrière

1. Dépasse légèrement la place.
2. Contrôle autour de toi.
3. Braque pour faire rentrer l’arrière.
4. Redresse quand la voiture est alignée avec les lignes.

Le stationnement en bataille peut être demandé en marche avant ou arrière selon la situation et le marquage. ([lePERMISLIBRE][3])

---

# 3) Le stationnement en épi

🎯 **Objectif :** se garer dans une place inclinée (souvent à 45°).

### Méthode :

1. Mets ton clignotant.
2. Approche-toi en suivant l’angle des lignes.
3. Tourne progressivement.
4. Ajuste avec les rétroviseurs.
5. Termine bien centré.

Astuce :

* Regarde les **lignes au sol** dans les rétroviseurs.
* Ne fixe pas uniquement l’avant : la trajectoire arrière est essentielle.

---

# 4) La marche arrière en ligne droite

🎯 **Objectif :** reculer sans dévier.

### Technique :

✅ Avant de commencer :

* Regarde autour du véhicule.
* Vérifie les angles morts.
* Mets le clignotant si nécessaire.

Pendant la marche arrière :

* Avance très lentement.
* Regarde alternativement :

  * vitre arrière,
  * rétroviseurs,
  * environnement extérieur.

```
Départ

🚙 ─────────►
(recul en ligne)
```

Le secret : **le regard guide le volant**. Si tu regardes trop près devant la voiture, tu corriges trop tard.

---

# 5) Le demi-tour en 3 temps

🎯 **Objectif : changer de direction dans une rue étroite.**

### Étape 1

* Contrôle autour de toi.
* Avance doucement en braquant.

```
🚙 ↪️
```

### Étape 2

* Passe en marche arrière.
* Braque dans l’autre sens.

```
↩️ 🚙
```

### Étape 3

* Repars dans le bon sens.

```
🚙 ➡️
```

À chaque mouvement :
✅ arrêt complet
✅ contrôle sécurité
✅ déplacement lent

---

# 6) Les règles d’or pour réussir toutes les manœuvres ⭐

### 1. Rouler au pas

Une manœuvre réussie se fait presque toujours **très lentement**.

### 2. Contrôler avant chaque mouvement

Avant d’avancer ou reculer :

* rétroviseurs,
* angle mort,
* piétons,
* véhicules.

### 3. Utiliser les repères

Chaque voiture a ses propres dimensions :

* hauteur des vitres,
* position des rétroviseurs,
* longueur du capot.

Les repères appris en auto-école doivent ensuite être adaptés à ton véhicule.

### 4. Ne pas hésiter à corriger

Faire une correction propre vaut mieux que forcer une mauvaise trajectoire.

## Mini entraînement conseillé 🏁

**Séance 1 :**

* Marche arrière en ligne droite ×10
* Bataille avant/arrière ×10

**Séance 2 :**

* Créneaux des deux côtés
* Demi-tours

**Séance 3 :**

* Parcours complet comme à l’examen
