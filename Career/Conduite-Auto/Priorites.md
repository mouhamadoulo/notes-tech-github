# 🚗 TUTO CONDUITE : Comprendre les priorités aux intersections (Permis B)

Les règles de priorité sont essentielles pour éviter les accidents. À chaque intersection, le conducteur doit se poser 3 questions :

1. **Y a-t-il un panneau ou un feu ?**
2. **Qui a la priorité ?**
3. **Dois-je ralentir, m’arrêter ou céder le passage ?**

# 1) ✅ La priorité à droite

## Principe

Quand aucune signalisation ne donne la priorité, **le véhicule qui arrive de votre droite est prioritaire**.

➡️ Vous devez :

* ralentir à l’approche de l’intersection ;
* regarder à droite ;
* laisser passer les véhicules venant de cette direction.

([En Voiture Simone][1])

### Exemple :

```
        🚗 A
        ↓

🚗 B  →  ✚  ←  🚗 C

        ↑
        🚗 D
```

Si vous êtes la voiture **D** :

* la voiture **C** arrive de votre droite → elle passe avant vous.
* vous devez attendre.

### Astuce examen 🚦

Posez-vous toujours la question :

**"Est-ce qu'une voiture arrive de ma droite ?"**

Si oui → je cède.

---

# 2) 🔻 Le cédez-le-passage

## Reconnaître le panneau

Le panneau est un triangle inversé bordé de rouge :

```
        🔻
   CÉDEZ LE PASSAGE
```

Il signifie :

➡️ Vous devez laisser passer les véhicules sur la route que vous allez traverser.

([public.codesrousseau.fr][2])

## Comment agir ?

À l’approche :

1. Je ralentis.
2. Je regarde à gauche et à droite.
3. Je m’arrête uniquement si un véhicule arrive ou si je ne peux pas m’engager en sécurité.
4. Je passe quand la voie est libre.

Exemple :

```
        🚗
        ↓
----------------
        |
        |
        🚘
       🔻
```

La voiture 🚘 doit attendre la voiture 🚗.

### Erreur fréquente ❌

Passer rapidement parce que "je vois personne".

Même avec un cédez-le-passage, il faut contrôler correctement.

---

# 3) 🛑 Le STOP

## Reconnaître le panneau

Le STOP est un panneau rouge en forme d’octogone :

```
     🛑
    STOP
```

Il impose un **arrêt obligatoire complet**.

([VérifPlace - Réservation Place Permis][3])

## La méthode :

À un STOP :

✅ Je m’arrête complètement.
✅ Les roues doivent être immobiles.
✅ Je contrôle les deux côtés.
✅ Je repars seulement si la route est libre.

Exemple :

```
        🚗
        ↓

----------------

        🛑
        🚘
```

Même si personne n’arrive → **je m’arrête quand même**.

### Erreur éliminatoire au permis ❌

Faire un "STOP glissé" :

* ralentir fortement ;
* regarder ;
* repartir sans arrêt complet.

# 4) 🔄 Giratoires et ronds-points

Attention : **un giratoire et un rond-point ne fonctionnent pas exactement pareil.**

---

## A) Carrefour à sens giratoire 🔄

Le cas le plus courant en France :

* Les véhicules déjà engagés dans l’anneau sont prioritaires.
* À l’entrée, on trouve généralement un panneau **cédez-le-passage**.

Schéma :

```
             ↑
          🚗

      ↺  🔵  ↺

🚗 →       🔻
      Entrée
```

### Pour entrer :

1. Je ralentis.
2. Je regarde à gauche.
3. Je laisse passer les véhicules déjà dans le cercle.
4. Je m’engage si c’est libre.

---

## Choisir sa voie dans un giratoire

### Première sortie à droite ➡️

* Je reste généralement sur la voie de droite.
* Clignotant droit.

```
🚗 → 🔄 → sortie 1
```

---

### Tout droit ⬆️

* Je peux rester à droite.
* Je mets le clignotant droit avant de sortir.

```
       ↑
🚗 →  🔄  → sortie
```

---

### Tour complet / demi-tour 🔁

* Je me place plutôt sur la voie intérieure si le marquage le prévoit.
* Clignotant gauche avant et droit avant la sortie.

---

## B) Rond-point

Un vrai rond-point peut fonctionner avec **la priorité à droite**.

Exemple :

```
        🚗
        ↓

   ↻  ⭕  ↻

🚗 →       🚗
```

Les véhicules qui entrent peuvent être prioritaires selon la signalisation.

➡️ Toujours regarder les panneaux avant de s’engager.

---

# 5) ❓ Intersections sans signalisation

C’est la situation qui piège beaucoup de candidats.

## Règle générale :

**Pas de panneau = priorité à droite.**

([En Voiture Simone][1])

Exemple :

```
          🚗
          ↓


🚗  →     ✚     ← 🚘


          ↑
          🚙
```

Chaque conducteur doit regarder à droite.

---

## Méthode du conducteur expérimenté 👀

À une intersection sans panneau :

### 1. Je ralentis

Même si je connais la route.

### 2. Je cherche les indices :

* panneaux cachés ;
* marquage au sol ;
* route prioritaire ;
* sorties de parking ou chemins privés.

### 3. Je regarde :

* gauche ;
* droite ;
* gauche encore.

---

# 🧠 Résumé rapide pour le permis

| Situation                 | Qui passe ?                     | Action                            |
| ------------------------- | ------------------------------- | --------------------------------- |
| Priorité à droite         | Celui qui vient de droite       | Je ralentis et je laisse passer   |
| Cédez-le-passage          | Les véhicules sur l'autre route | Je passe seulement si c'est libre |
| STOP                      | Personne avant mon arrêt        | Arrêt complet obligatoire         |
| Giratoire                 | Véhicules déjà dans l’anneau    | Je cède avant d’entrer            |
| Intersection sans panneau | Priorité à droite               | Je contrôle à droite              |

---

# ⭐ La règle d’or

Avant chaque intersection :

**Je ralentis → j’observe → j’identifie la priorité → je décide.**

Un bon conducteur ne cherche pas seulement à savoir "qui passe", il anticipe ce que les autres vont faire. 🚗
