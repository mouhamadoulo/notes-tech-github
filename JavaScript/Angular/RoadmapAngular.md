## 1-Bases
- Javascript (ES6+ syntax) : classes, modules, Arrow functions, destructuring, ...
- TypeScript (surcouche de Javascript) : types, interfaces, classes, et decorators, ...
- HTML5/CSS3, SCSS

## 2-Bien commencer Angular
- Notion de single-page applications ? et le pourquoi ? 
- Angular CLI : interface de commande d'Angular pour créer des projets , faire des build, des tests, ...
- Modules et Composants
- Templates et Data binding
- Directives
- Control Flow

## 3-Concepts avancés de Angular
- Services et Injection de dépendances
- Les Formulaires : template-driven and reactive forms
- HTTP Client
- Routes et Navigation

## 4-State Management (Gestion d'état) - programmation réactive
- RxJS : programmation réactive, observables, operators, flux de données asynchrone
- NgRx : bibliothèque de gestion d'état basé sur le pattern Redux, concepts clés (actions, reducers, effects et selectors)
- NgXs : gestion d'état simplifié
- Signal

## 5-Style dans Angular
- Angular Material : UI component library, to implement Google's Material Design in your application
- PrimeNg
- SCSS : Explore SCSS for writing modular and maintainable stylesheet

## 6-Test des applis Angular
- Tests Unitaires (Unit Testing) : avec Jasmine et Karma
- Tests de bout en bout (End-to-End Testing) : avec Protractor(déprécié), Cypress (plus moderne)

## 7-Optimisation Performance
- Change Detection
- Lazy Loading
- Ahead-of-Time (AOT) Compilation

## 8-Building and Deployment
- Angular CLI: Use Angular CLI commands to build and serve your application
- Continuous Integration/Continuous Deployment (CI/CD): Set up CI/CD pipelines using tools like GitHub Actions, Travis CI, or CircleCI for automated testing and deployment
- Deployment: Learn how to deploy your Angular application to various environments like Firebase, AWS, or Azure

## 9-Angular Ecosystem
- Angular Universal: Learn Angular Universal for server-side rendering (SSR) to improve performance and SEO.
- Ionic: pour créer des applications mobiles cross-platform avec Angular.
- Nx: Explore Nx, a set of extensible dev tools for monorepos, to manage large Angular projects efficiently.

## 10-Suivre l'évolution de Angular avec la communauté
Angular évolue en permanence (une nouvelle version majeure chaque 6 mois). 
Restez à jour avec les dernières tendances et les meilleures pratiques:
- Official Documentation: Regularly check the official Angular documentation.
- Community Forums: Participate in Angular communities on platforms like Stack Overflow, Reddit, and GitHub.
- Blogs and Tutorials: Follow popular Angular blogs and tutorials to stay informed about new features and techniques.
