Il existe plusieurs concepts fondamentaux de l’IA moderne qui valent vraiment la peine d’être connus. <br>
Je te les classe par importance pour quelqu’un qui veut comprendre l’IA actuelle (et éventuellement créer des systèmes).

# 🧠 1. Deep Learning
Le Deep Learning est la base de presque toute l’IA moderne.<br>
C’est une branche du Machine Learning qui utilise des réseaux de neurones artificiels avec de nombreuses couches.

Applications :
- vision par ordinateur
- reconnaissance vocale
- LLM
- voitures autonomes

Les LLM comme GPT-4 reposent entièrement sur cette approche.

# 🔤 2. NLP (Natural Language Processing)
Le Natural Language Processing est la discipline qui permet aux machines de comprendre le langage humain.

Exemples :
- traduction automatique
- analyse de sentiment
- résumé de texte
- chatbots

Les LLM représentent aujourd’hui la forme la plus avancée du NLP.

# ⚙️ 3. Transformers
La majorité des modèles modernes utilisent l’architecture ```Transformer architecture```.<br>
Elle est basée sur un mécanisme appelé ```Attention mechanism```.

Pourquoi c’est révolutionnaire :
- comprend le contexte d’une phrase
- fonctionne très bien sur de gros volumes de données
- s’entraîne efficacement sur GPU

C’est ce qui a rendu possibles les LLM.

# 🧮 4. Embeddings
Les Word Embedding transforment du texte en vecteurs numériques.

Exemple :
```
"chat" → [0.12, -0.45, 0.91 ...]
```
Grâce à ça, l’IA peut :
- mesurer la similarité entre textes
- faire de la recherche sémantique
- alimenter des systèmes RAG

# 🗄️ 5. Vector Databases
Pour stocker les embeddings on utilise des bases vectorielles.

Exemples :
- FAISS
- Pinecone
- Milvus

Elles permettent de faire de la recherche par similarité très rapide.<br>
C’est un élément clé des architectures RAG.

# 🤖 6. Agents IA
Les agents IA sont une évolution récente.

Un agent :
- planifie des actions
- utilise des outils
- raisonne sur plusieurs étapes

Certains frameworks populaires :
- LangChain
- AutoGPT

Les agents permettent de créer des systèmes qui résolvent des tâches complexes automatiquement.

# 🧾 7. Fine-tuning
Le Fine-tuning consiste à réentraîner légèrement un modèle existant pour une tâche spécifique.

Exemples :
- chatbot médical
- assistant juridique
- générateur de code

C’est souvent utilisé avec des modèles comme LLaMA.

# 🧩 8. Prompt Engineering
Le Prompt Engineering consiste à formuler les instructions pour obtenir de meilleures réponses.

Techniques connues :
- Chain-of-Thought prompting
- few-shot prompting
- role prompting

C’est une compétence clé pour travailler avec les LLM.

# 👁️ 9. Computer Vision
Le Computer Vision permet aux machines de comprendre les images.

Applications :
- reconnaissance faciale
- analyse médicale
- voitures autonomes

Exemples de modèles :
- YOLO
- Stable Diffusion

# 🎨 10. IA générative
L’Generative AI est la branche de l’IA qui crée du contenu :
- texte
- images
- vidéo
- audio

Exemples :
- ChatGPT
- Midjourney
- Stable Diffusion

# 🧭 Concepts avancés
Certains concepts deviennent très importants aujourd’hui :
- Mixture of Experts
- Reinforcement Learning
- Multimodal AI
- Diffusion model
