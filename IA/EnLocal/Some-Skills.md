Pour du **vibe coding** avec OpenCode, je te conseille d'installer un ensemble de skills couvrant tout le cycle de développement plutôt qu'un seul skill.

## 1. frontend-design ⭐⭐⭐⭐⭐

À utiliser pour :

* Design système (couleurs, typographie, spacing)
* Wireframes et UX
* Responsive mobile/desktop
* Composants React/Tailwind réutilisables

Exemple :

```text
Design the UI for a personal finance SaaS.
```

---

## 2. system-design ⭐⭐⭐⭐⭐

À utiliser pour :

* Architecture backend
* Découpage en services
* Modélisation des données
* Choix techniques et trade-offs

Exemple :

```text
Design the architecture for MOLOFINANCE.
```

---

## 3. code-review ⭐⭐⭐⭐⭐

À utiliser pour :

* Détecter les bugs
* Améliorer la lisibilité
* Vérifier les bonnes pratiques
* Réduire la dette technique

Exemple :

```text
Review the current codebase and suggest improvements.
```

---

## 4. refactoring ⭐⭐⭐⭐☆

À utiliser pour :

* Réorganiser le code
* Supprimer les duplications
* Introduire des patterns
* Simplifier les composants complexes

Exemple :

```text
Refactor this Next.js project following clean architecture.
```

---

## 5. debugging ⭐⭐⭐⭐⭐

À utiliser pour :

* Corriger les erreurs Next.js
* Résoudre les problèmes Docker
* Déboguer les erreurs de build
* Diagnostiquer les problèmes de performance

Exemple :

```text
Investigate why the application fails during build.
```

---

## 6. security-review ⭐⭐⭐⭐⭐

Très utile pour tes projets SaaS :

* Authentification
* Gestion des secrets
* Vérification OWASP
* Sécurisation des API
* Gestion des permissions

Exemple :

```text
Review the project for security vulnerabilities.
```

---

## 7. test-writer ⭐⭐⭐⭐☆

À utiliser pour :

* Générer des tests unitaires
* Générer des tests d'intégration
* Configurer Vitest ou Jest
* Couvrir les cas limites

Exemple :

```text
Generate tests for the expense management module.
```

---

## 8. docs-writer ⭐⭐⭐⭐☆

À utiliser pour :

* README professionnel
* Documentation API
* Guides d'installation
* Documentation d'architecture

Exemple :

```text
Generate project documentation and onboarding guide.
```

---

# Stack idéale pour tes projets Java/Angular et Next.js

Je te conseille ce pack :

```text
frontend-design
system-design
security-review
debugging
refactoring
test-writer
docs-writer
code-review
```

Pour ton projet **MOLOFINANCE**, le workflow pourrait être :

```text
1. system-design
2. frontend-design
3. implementation
4. test-writer
5. security-review
6. code-review
7. docs-writer
8. debugging
```

Avec cette combinaison, OpenCode se rapproche d'une petite équipe composée d'un architecte, d'un designer, de développeurs, d'un QA et d'un expert sécurité.
