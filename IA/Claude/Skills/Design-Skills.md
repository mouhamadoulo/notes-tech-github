# <ins>Frontend Design Skills</ins>

## Impeccable
Impeccable est généralement utilisé pour produire une UI extrêmement propre, polie et cohérente visuellement.<br>
Son rôle :
- améliorer la qualité perçue du design
- corriger les détails visuels subtils
- alignements parfaits
- spacing premium
- hiérarchie visuelle forte
- finitions “Apple-like”
- suppression des éléments visuellement “cheap”

En gros :
> rendre une interface “professionnelle + premium”

C’est souvent un skill orienté :
> pixel perfection + visual polish

## SkillUI 
SkillUI sert à :
- générer des composants UI propres
- améliorer l’ergonomie
- proposer de meilleures structures de layout
- optimiser l’UX des flows
- produire des interfaces plus intelligentes

Focus :
> UI system + composant design

Plus orienté :
- architecture UI
- composants réutilisables
- cohérence design system

moins orienté “beauté pure” que Impeccable.

## Taste skill
Taste skill = goût visuel.

C’est probablement le skill le plus sous-estimé.

Il sert à :
- choisir ce qui est élégant
- éviter le design cheap
- savoir quoi supprimer
- savoir quand s’arrêter
- faire les bons arbitrages visuels

Focus :
> bon goût

C’est souvent ce qui sépare : 
> junior design vs senior design

## Google Fonts
Google Fonts sert à :
- choisir des typographies professionnelles
- améliorer la lisibilité
- renforcer l’identité visuelle
- créer du contraste visuel
- rendre une UI instantanément meilleure

Une mauvaise font détruit une bonne UI.

Une bonne font améliore tout.

Focus :
> typography system

extrêmement important.

## playwright-cli
Playwright CLI sert à :
- tester l’UI automatiquement
- vérifier responsive
- screenshots automatiques
- validation cross-browser
- détection de bugs visuels
- testing end-to-end

Super utile pour :
- Claude Code qui build des apps
- agents autonomes
- validation UI automatique

Focus :
> QA + UI verification

C’est critique pour :
> “l’IA code → mais est-ce que ça marche vraiment ?”
