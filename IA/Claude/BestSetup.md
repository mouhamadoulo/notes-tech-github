# Mon Setup Claude Code
Les outils que j'utilise dans un projet

## Le Plugin : Context7
Plugin officiel d'Anthropic avec +250 000 installations

Sans Context7, Claude te réponds de mémoire avec potentiellement des trucs qui ont changé depuis la dernière MAJ
> Context7 va chercher la doc en temps réel

**Points +**
- Tu l'installes, tu l'oublies
- Tourne en fond en permanence
- Un mot clé suffit à rajouter sur tes prompts : `use context7`

**Ce qui pique**
- Consomme du contexte
- Toutes les libs ne sont pas indexées (Solution : envoyer le repo Github à Context7)
