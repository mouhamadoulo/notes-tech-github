# Les agents Claude Code expliqués simplement

Un **agent Claude Code** est une intelligence artificielle qui peut travailler directement sur un projet logiciel comme un développeur junior très rapide.

Au lieu de simplement répondre à des questions, l'agent peut :

- Lire le code d'un projet.
- Comprendre la structure des fichiers.
- Modifier du code existant.
- Créer de nouveaux fichiers.
- Corriger des bugs.
- Écrire des tests.
- Lancer certaines commandes dans le terminal.
- Réaliser des tâches complexes de manière autonome.

## Différence entre un chatbot classique et un agent

### Chatbot classique

Tu demandes :

> « Écris-moi une fonction pour trier une liste. »

L'IA te répond avec du code, mais c'est toi qui dois le copier et l'intégrer.

### Agent Claude Code

Tu demandes :

> « Corrige le bug de connexion utilisateur dans mon projet. »

L'agent peut :

1. Explorer le dépôt.
2. Trouver les fichiers concernés.
3. Identifier la cause du bug.
4. Modifier le code.
5. Ajouter ou mettre à jour les tests.
6. Te présenter les changements réalisés.

## Comment Claude Code fonctionne

Claude Code dispose généralement de plusieurs capacités :

- Accès aux fichiers du projet.
- Recherche dans le code.
- Édition de fichiers.
- Exécution de commandes terminal.
- Lecture de la documentation.
- Raisonnement sur plusieurs étapes.
