# Dev Junior à Dev Sénior
Passer de développeur junior à développeur senior ne signifie pas seulement mieux coder. <br>
Cela implique de maîtriser tout l’écosystème du développement logiciel : collaboration, architecture, qualité du code, <br>
déploiement, performance, sécurité, etc.<br>
Un développeur senior comprend comment un système fonctionne dans son ensemble, pas seulement une fonctionnalité.

## 1. <ins>Outils de collaboration</ins>
```
Les outils de collaboration permettent aux équipes de communiquer, 
organiser le travail et suivre l’avancement des projets.
Un développeur junior utilise ces outils pour suivre des tâches.
Un développeur senior les utilise pour organiser un projet, structurer le travail 
et faciliter la communication entre équipes.
```

Exemple d'outils :
- **Google Meet** réunions techniques, daily meeting
- **Trello** gestion de tâches avec Kanban
- **Notion** documentation technique
- **Discord** communication rapide dans l’équipe
- **toggl track** suivi du temps de travail
- **Github** gestion du code et collaboration via Pull Requests

## 2. <ins>Langages de programmation</ins>
```
Un développeur junior connaît généralement un langage principal.
Un développeur senior comprend plusieurs langages et leurs paradigmes.
```

Exemple :
- Java
- PHP
- Python
- JavaScript
- Go

**Compétences senior**<br>
=> comprendre les paradigmes :
- programmation orientée objet
- fonctionnelle
- concurrente

=> écrire du code maintenable et performant

## 3. <ins>Les APIs de développement</ins>
```
Les APIs permettent aux applications de communiquer entre elles.
Un junior consomme des APIs.
Un senior conçoit et sécurise des APIs robustes.
```

Types d’API
- REST
- GraphQL
- gRPC

Outils
- Postman
- Swagger
- Insomnia

Compétences senior
- design REST propre
- versionning d’API
- gestion des erreurs
- rate limiting

Les frameworks accélèrent le développement en fournissant une structure prête à l’emploi.

## 6. <ins>Testing</ins>
```
Le testing garantit que le logiciel fonctionne correctement.
Un junior écrit peu de tests.
Un senior construit une stratégie de tests complète.
```

Types de tests
- tests unitaires
- tests d’intégration
- tests end-to-end

Exemple : 
- JUnit (pour Java)
- Jest  (pour JavaScript)
- Cypress

## 11. <ins>Design Patterns</ins>
```
Les design patterns sont des solutions standard à des problèmes récurrents en programmation.
```

Exemple de Design Patterns :
- Singleton
- Factory 
- Observer 
- Decorator

Un senior sait quand utiliser un pattern et quand l’éviter.

## 12. <ins>Architecture logicielle</ins>
```
L’architecture définit comment les composants d’un logiciel sont organisés.
```

Exemple d'achitectures : 
- Monolithe
- MVC
- Microservices
- Clean Architecture
- Hexagonal Architecture

Compétence senior
- structurer un projet pour qu’il soit maintenable sur plusieurs années

## 13. <ins>System design</ins>
```
Le system design concerne la conception de systèmes à grande échelle.
```

Exemple : 
- Scalabilité
- Load Balancing
- Gestion de cache
- Database sharing

## 14. <ins>Monitoring / Observabilité</ins>
```
Une application en production doit être surveillée pour détecter les problèmes.
```

Exemple :
- Prometheus
- Grafana
- Sentry

Ce que fait un senior
- surveiller les performances
- analyser les logs
- détecter les incidents rapidement

# ✅ Résumé
La progression vers senior passe par 4 grands axes :
- 1. Code solide
(langages, algorithmes, design patterns)

- 2. Architecture et conception
(system design, architecture logicielle)

- 3. Qualité et fiabilité
(testing, CI/CD, monitoring)

- 4. Production et collaboration
(cloud, API, outils d’équipe)
