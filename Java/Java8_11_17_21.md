# Les différences entre les versions Java 8, 11, 17 et 21
Voici un résumé clair des principales nouveautés des versions Java 8, 11, 17 et 21 (toutes des LTS – Long Term Support), 
avec l’idée de ce que ça a vraiment changé pour les devs 👇

## ☕ <ins>Java 8 (2014) — la révolution</ins>
Probablement la version la plus marquante de Java.<br>
**Nouveautés majeures :**
- Expressions lambda → programmation fonctionnelle
- Stream API → manipulation fluide des collections
- Optional → meilleure gestion du null
- Date & Time API (java.time) → enfin une API propre pour les dates
- Interfaces avec méthodes default
- Nashorn (moteur JavaScript – aujourd’hui retiré)
👉 Java moderne commence vraiment ici.

### 1.Expressions Lambda
Avant :
```java
Runnable r = new Runnable() {
    public void run() {
        System.out.println("Hello");
    }
};
```
Java 8 :
```java
Runnable r = () -> System.out.println("Hello");
```
➡️ Moins de code, plus lisible.

### 2.Stream API
Avant (boucles impératives) :
```java
int sum = 0;
for (int n : numbers) {
    if (n % 2 == 0) {
        sum += n;
    }
}
```
Java 8 :
```java
int sum = numbers.stream()
                 .filter(n -> n % 2 == 0)
                 .mapToInt(Integer::intValue)
                 .sum();
```
➡️ Déclaratif, chaînable, lisible.

### 3.Optional (fin des null à rallonge)
Avant :
```java
if (user != null && user.getEmail() != null) {
    send(user.getEmail());
}
```
Java 8 :
```java
Optional.ofNullable(user)
        .map(User::getEmail)
        .ifPresent(this::send);
```
➡️ Le null devient explicite et contrôlé.

### 4.Nouvelle API Date & Time (java.time)
Avant (API cassée 😬) :
```java
Date date = new Date();
```
Java 8 :
```java
LocalDate today = LocalDate.now();
LocalDate birthday = LocalDate.of(1995, 5, 12);

Period age = Period.between(birthday, today);
```
➡️ Immuable, claire, thread-safe.

### 5.Méthodes default dans les interfaces
Avant : impossible d’ajouter une méthode sans tout casser.

Java 8 :
```java
interface Vehicle {
    void move();

    default void start() {
        System.out.println("Starting...");
    }
}
```
➡️ Évolution d’API sans casser les implémentations existantes.

### 6.Références de méthodes
Avec lambda :
```java
list.forEach(s -> System.out.println(s));
```
Encore plus court :
```java
list.forEach(System.out::println);
```
➡️ Quand une lambda appelle juste une méthode.

### 7.API Collections enrichie
```java
list.removeIf(s -> s.isEmpty());

list.forEach(System.out::println);

map.forEach((k, v) -> System.out.println(k + " = " + v));
```
➡️ Les collections deviennent fonctionnelles.

### 8.Nashorn (moteur JavaScript – historique)
```java
ScriptEngine engine = new ScriptEngineManager()
        .getEngineByName("nashorn");

engine.eval("print('Hello from JS')");
```
⚠️ Présent en Java 8, supprimé depuis Java 15.

## ☕ <ins>Java 11 (2018) — nettoyage + standardisation</ins>
Deuxième LTS après Java 8, très adoptée en entreprise.<br>
**Nouveautés majeures :**
- Suppression de Java EE / CORBA du JDK
- Nouvelle API HTTP standard (HttpClient)
- var pour les paramètres lambda
- Nouvelles méthodes sur String (isBlank(), lines(), repeat(), strip())
- Lancement direct d’un fichier .java
- ZGC & Epsilon GC (expérimentaux)
👉 Moins de legacy, plus de clarté.

### 1.Nouvelle API HTTP standard (HttpClient)
Avant → libs externes (Apache, OkHttp…)

Java 11 :
```java
HttpClient client = HttpClient.newHttpClient();

HttpRequest request = HttpRequest.newBuilder()
        .uri(URI.create("https://api.example.com/users"))
        .GET()
        .build();

HttpResponse<String> response =
        client.send(request, HttpResponse.BodyHandlers.ofString());

System.out.println(response.body());
```
➡️ HTTP natif, simple, async-ready.

### 2.var dans les paramètres lambda
Avant :
```java
list.stream()
    .map((String s) -> s.toUpperCase())
    .forEach(System.out::println);
```

Java 11 :
```java
list.stream()
    .map((var s) -> s.toUpperCase())
    .forEach(System.out::println);
```

Utile surtout pour :
```java
(@Nonnull var s) -> s.toUpperCase()
```
➡️ Meilleure lisibilité + annotations possibles.

### 3.Nouvelles méthodes sur String
```java
"   ".isBlank();           // true
" a\nb\nc ".lines();       // Stream<String>
"Hi ".repeat(3);           // "Hi Hi Hi "
"  text  ".strip();        // "text"
```
➡️ Fini les helpers maison.

### 4.Lancement direct d’un fichier .java
Avant :
```java
javac Hello.java
java Hello
```

Java 11 :
```java
java Hello.java
```
➡️ Idéal pour scripts, tests rapides, POC.

### 5.Suppression de Java EE / CORBA du JDK
Avant (Java 8) :
```java
import javax.xml.ws.Service; // JAX-WS dans le JDK
```

Java 11 ❌ :
```java
Compilation error: package javax.xml.ws does not exist
```

Solution :
```java
<!-- Dépendance externe -->
<dependency>
  <groupId>jakarta.xml.ws</groupId>
  <artifactId>jakarta.xml.ws-api</artifactId>
</dependency>
```
➡️ JDK plus léger, dépendances explicites.

### 6.ZGC (expérimental à l’époque)
Activation :
```bash
java -XX:+UseZGC -jar app.jar
```
➡️ Pauses GC très faibles, même avec gros heaps.

### 7.Epsilon GC (No-Op GC)
Activation :
```bash
java -XX:+UseEpsilonGC -jar app.jar
```

➡️ Utile pour :
- benchmarks
- tests mémoire
- apps très courtes


## ☕ <ins>Java 17 (2021) — Java devient très solide</ins>
Version LTS ultra-populaire aujourd’hui.<br>
**Nouveautés majeures :**
- Records → classes immuables ultra-compactes
- Sealed Classes → contrôle de l’héritage
- Pattern Matching (instanceof amélioré)
- Switch expressions (finalisées)
- Nouveau rendu interne (Metal remplacé)
- ZGC & G1 très matures
- Fort encapsulage des modules internes
👉 Excellent équilibre entre modernité et stabilité.

### 1.Records (classes immuables ultra-compactes)
Avant :
```java
class User {
    private final String name;
    private final int age;

    // constructeur, getters, equals, hashCode, toString...
}
```

Java 17 :
```java
record User(String name, int age) {}
```

Utilisation :
```java
User u = new User("Alice", 30);
System.out.println(u.name());
```
➡️ Parfait pour DTO, events, value objects.

### 2.Sealed Classes (héritage contrôlé)
```java
sealed interface Shape permits Circle, Rectangle {}
```
```java
final class Circle implements Shape {
    double radius;
}
```
```java
final class Rectangle implements Shape {
    double width, height;
}
```
➡️ Le compilateur connaît tous les sous-types possibles.

### 3.Pattern Matching pour instanceof
Avant :
```java
if (obj instanceof String) {
    String s = (String) obj;
    System.out.println(s.length());
}
```

Java 17 :
```java
if (obj instanceof String s) {
    System.out.println(s.length());
}
```
➡️ Moins de cast, moins d’erreurs.

### 4.Switch expressions (finalisées)
Avant :
```java
int result;
switch (day) {
    case MONDAY:
    case FRIDAY:
        result = 6;
        break;
    default:
        result = 0;
}
```

Java 17 :
```java
int result = switch (day) {
    case MONDAY, FRIDAY -> 6;
    default -> 0;
};
```
➡️ Expression claire, pas de break oublié.

### 5.Pattern matching avec switch (première version stable)
```java
static String format(Object o) {
    return switch (o) {
        case Integer i -> "int " + i;
        case String s  -> "String " + s;
        case null      -> "null";
        default        -> "Object";
    };
}
```
➡️ Lisible + exhaustivité contrôlée.

### 6.Encapsulation forte des modules internes
Avant (Java 8 😬) :
```java
sun.misc.Unsafe unsafe = ...
```

Java 17 ❌ :
```text
IllegalAccessError
```

Solution :
```bash
--add-opens java.base/sun.misc=ALL-UNNAMED
```
➡️ Meilleure sécurité, moins de hacks JVM.

### 7.ZGC & G1 très matures
Activation G1 (par défaut) :
```bash
java -XX:+UseG1GC -jar app.jar
```

Activation ZGC :
```bash
java -XX:+UseZGC -jar app.jar
```
➡️ Pauses GC très courtes, même à grande échelle.

### 8.Nouveau rendu interne (Metal remplacé)
Aucun code à écrire :
```text
UI Swing plus moderne automatiquement
```
➡️ Impact surtout desktop (rare aujourd’hui).

### Exemple réaliste combiné (Java 17)
```java 
record Event(String type, Object data) {}

static String handle(Event e) {
    return switch (e.data()) {
        case String s  -> "text: " + s;
        case Integer i -> "number: " + i;
        default        -> "unknown";
    };
}
```
➡️ Records + switch + pattern matching = code clean ✨

## ☕ <ins>Java 21 (2023) — Java nouvelle génération</ins>
Dernière LTS, très orientée performance et concurrence.<br>
**Nouveautés majeures :**
- Virtual Threads (Project Loom) → concurrence massive simple et performante
- Pattern Matching étendu (switch, records, null)
- Sequenced Collections (List, Set, Map avec ordre garanti)
- String Templates (preview)
- Scoped Values (meilleure alternative à ThreadLocal)
- Structured Concurrency
- Améliorations JVM & GC
👉 Java devient redoutable pour les apps hautement concurrentes.

### 1.Virtual Threads (Project Loom)
Avant (threads lourds) :
```java
ExecutorService pool = Executors.newFixedThreadPool(100);
pool.submit(() -> callService());
```

Java 21 :
```java
try (var executor = Executors.newVirtualThreadPerTaskExecutor()) {
    executor.submit(() -> callService());
}
```

Ou encore plus simple :
```java
Thread.startVirtualThread(() -> callService());
```
➡️ Des millions de threads légers, écriture synchrone, perf async.

### 2.Structured Concurrency
```java
try (var scope = new StructuredTaskScope.ShutdownOnFailure()) {

    Future<User> user =
        scope.fork(() -> loadUser());

    Future<Order> order =
        scope.fork(() -> loadOrder());

    scope.join();           // attend tout
    scope.throwIfFailed();  // stoppe si erreur

    return new Result(user.resultNow(), order.resultNow());
}
```
➡️ Gestion propre des threads enfants (comme un try-with-resources).

### 3.Scoped Values (alternative à ThreadLocal)
Avant :
```java 
static ThreadLocal<String> USER = new ThreadLocal<>();
``` 

Java 21 :
```java 
static final ScopedValue<String> USER = ScopedValue.newInstance();

ScopedValue.where(USER, "alice").run(() -> {
    process();
});
```
```java 
void process() {
    System.out.println(USER.get());
}
```
➡️ Plus sûr, plus performant, compatible virtual threads.

### 4.Pattern Matching étendu (switch + records)
```java 
record Point(int x, int y) {}

static String describe(Object o) {
    return switch (o) {
        case Point(int x, int y) -> "x=" + x + ", y=" + y;
        case String s            -> "text: " + s;
        case null                -> "null";
        default                  -> "unknown";
    };
}
```
➡️ Déstructuration + exhaustivité = zéro casting.

### 5.Sequenced Collections
```java 
SequencedCollection<String> list = new ArrayList<>();

list.addFirst("A");
list.addLast("B");

System.out.println(list.getFirst()); // A
System.out.println(list.getLast());  // B

```
Aussi pour Map :
```java 
SequencedMap<String, Integer> map = new LinkedHashMap<>();

map.putFirst("one", 1);
map.putLast("two", 2);

```
➡️ L’ordre devient officiellement garanti.

### 6.String Templates (preview)
```java
String name = "Alice";
int age = 30;

String s = STR."Name: \{name}, age: \{age}";
```
➡️ Plus lisible que + ou String.format().
⚠️ Preview → peut évoluer.

### 7.Améliorations JVM & GC
Activation ZGC (prod-ready) :
```bash
java -XX:+UseZGC -jar app.jar
```
➡️ Pauses < 10 ms, même avec gros heap.

### Exemple moderne combiné (Java 21)
```java 
record Request(String userId) {}

static void handle(Request r) {
    ScopedValue.where(USER, r.userId()).run(() -> {
        Thread.startVirtualThread(() -> {
            System.out.println("User = " + USER.get());
        });
    });
}
```
➡️ Virtual Threads + Scoped Values = Java cloud-native ☁️🔥

| **Java 17** | Robustesse & design moderne |
